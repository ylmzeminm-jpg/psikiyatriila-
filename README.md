# Psikiyatride Somatik Tedaviler – Çalışma Kartları

Benzodiazepinler, antidepresanlar, antipsikotikler, duygudurum düzenleyiciler, Alzheimer ilaçları, EKT ve TMS için:

- 131 çalışma kartı (endikasyon, kontrendikasyon, yan etki, mekanizma, doz, piyasa adı)
- Aranabilir ilaç tablosu (jenerik ad, piyasa adı, grup, form, doz)
- Ezber kodlamaları

Kaynak: D4 Psikiyatri ders kitabı, "Psikiyatrik Hastalıklarda Somatik Tedaviler" bölümü.

Tek dosyalık statik sayfadır; GitHub Pages ile yayınlanabilir.
